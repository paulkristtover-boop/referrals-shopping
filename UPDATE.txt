Economics model and launch controls
- Each approved referral/task pays the earner ₦15. A fully completed 1,000-referral Regular Spark order costs ₦15,000 in direct rewards and sells for ₦25,900, leaving ₦10,900 (42.1%) contribution before gateway fees, support, refunds, taxes and fixed overhead.
- The 250-referral Mini tier sells for ₦6,900; direct reward cost is ₦3,750. The small tiers are intended to lower the entry point without selling below direct fulfilment cost.
- Deposit-required Vault packages carry a modest premium because of additional review and risk handling.
- Do not treat the contribution figure as net profit. Reconcile Flutterwave/crypto fees, VAT/tax obligations, failed-task/refund rates, fraud, support and operating costs monthly. Keep a separate funded reward reserve; never spend unearned task liabilities.
- The free 50-referral starter is a customer-acquisition expense: budget up to ₦750 per redeemed account if all 50 tasks are approved. Limit it to one per verified account and monitor abuse.
- Before launch, test 250/500/1,000 task completion and payout paths, then review actual completion and gateway costs. If realised variable cost rises, increase package prices or lower the advertised delivery volume; do not silently reduce an active task's promised reward.

Vercel deployment
The repository is a Vite project (`vite` dependency, `dev` and `build` scripts). Vercel detects Vite and installs dependencies from the committed package manifest/lockfile, then runs `npm run build`. Set the project Framework Preset to Vite if it is not detected, Build Command to `npm run build`, and Output Directory to `dist`. No manual Vite installation step is needed. Commit `package-lock.json` for reproducible installs if npm is your package manager.
